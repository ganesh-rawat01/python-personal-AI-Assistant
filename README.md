Python Personal AI Assistant

A voice-controlled personal AI assistant built using Python. It can perform basic tasks through voice commands and respond using speech.

Features

- Voice command recognition
- Text-to-speech responses
- Open websites like Google, YouTube, Facebook and LinkedIn
- Play music using voice commands
- Fetch latest news headlines
- AI-based responses using OpenAI API

Technologies Used

- Python
- SpeechRecognition
- PyAudio
- Pyttsx3
- PyAutoGUI
- Requests
- OpenAI API

Installation

Install the required libraries:

pip install SpeechRecognition pyttsx3 requests openai

Install PyAudio separately if required.

How to Run

python main.py

Requirements

- Python installed
- Working microphone
- Internet connection
- API keys for services that require them

Note

OpenAI API and NewsAPI features require their respective API keys. Never upload your private API keys to GitHub.

This project was developed as a Python learning project to practice voice recognition, automation and API integration.
